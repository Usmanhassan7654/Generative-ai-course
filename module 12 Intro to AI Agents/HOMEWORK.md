# 📝 Module 12 Homework

> Module 12 · Designed by **Engr Usman Hasan**

## Saturday → Sunday (15 minutes)
Think of an agent for **your own project** (or pick one: a shop helper, a clinic appointment helper, a university admissions helper, a cricket stats helper).

Write on paper or in a text file:
1. The agent's **job** in one sentence.
2. **3 tools** it needs. For each: a name, a one-line description, and its input.
3. **One question** a user might ask that needs at least 2 of those tools.

Bring it to Sunday's class. You will turn it into a blueprint and then real code.

## After Sunday: mini-project
Build your agent in the Day 2 notebook (Part 6, Boss level):
- [ ] At least **3 tools** with clear docstrings (one can be a calculator or a rule search)
- [ ] A **system prompt** that says what it must never do
- [ ] **Short-term memory** (checkpointer + `thread_id`)
- [ ] A **step limit** (`recursion_limit`)
- [ ] **Bonus:** long-term memory (a JSON diary) or `interrupt()` before one risky action
- [ ] Run **3 test questions**: one easy (1 tool), one hard (2+ tools), one with no tool needed (e.g. a greeting)

Submit: the notebook + a screenshot of one run showing the tool calls.
